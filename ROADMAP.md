# 🎯 План подготовки: Junior Data Analyst + BI Analyst за 4 недели

**Цель:** Выйти на рынок сразу под **два профиля вакансий** (Junior Data Analyst и Junior BI-аналитик), удвоив количество откликов и приглашений на стажировки/собеседования. В багаже: рабочий промышленный софт, боевой GitHub и 2 разноплановых проекта.

---

## ⚡ Синергия двух треков (Data + BI)
* **SQL (Общий фундамент 100%):** Базы данных, сложные выборки, оконные функции, агрегаты. Без него не берут ни в Data, ни в BI.
* **Python (Pandas):** Оружие Data Analyst — быстрая обработка сырых данных, ad-hoc исследования, когорты и статистика.
* **Power BI & DataLens:** Оружие BI Analyst — проектирование моделей («звезда»), DAX-меры, интерактивные дашборды для бизнеса.

## 🛠️ Боевой стек и софт (как на реальной работе)
1. **Редактор кода:** VS Code + Git / GitHub (аккаунт, коммиты, портфолио).
2. **Клиент баз данных:** DBeaver (индустриальный стандарт подключения к любым базам).
3. **Анализ данных:** Python 3, Pandas, NumPy, Jupyter Notebooks.
4. **BI-системы:** 
   - **Microsoft Power BI Desktop** (модели данных, Power Query, DAX).
   - **Yandex DataLens** (публичный облачный BI для живых ссылок в резюме).
5. **Табличные процессоры:** Excel / Google Sheets (Сводные таблицы Pivot, ВПР/XLOOKUP, СУММЕСЛИМН, экспорт витрин).

## 💼 2 Проекта для резюме и GitHub

### 📌 Проект 1 (Data Analyst Track): Сквозной когортный анализ и воронка Retention финтех-сервиса
* **Стек:** SQL (CTE, оконные функции) $\rightarrow$ Python / Pandas (когортная матрица) $\rightarrow$ Seaborn (Heatmap).
* **Бизнес-задача:** Анализ оттока клиентов по месяцам, расчет LTV и поиск узких мест воронки.
* **Результат:** Репозиторий на GitHub с чистым кодом, графиками и выводами для C-Level.

### 📌 Проект 2 (BI Analyst Track): Интерактивный Executive Dashboard продаж и клиентской аналитики
* **Стек:** Модель данных «Звезда» $\rightarrow$ DAX (меры `CALCULATE`, `SAMEPERIODLASTYEAR`, маржинальность) $\rightarrow$ Power BI Desktop / Yandex DataLens.
* **Бизнес-задача:** Дашборд для топ-менеджмента с ключевыми KPI, срезами по регионам, динамикой выручки и фильтрами.
* **Результат:** Файл `.pbix` в GitHub + интерактивная живая ссылка на дашборд прямо в резюме.
